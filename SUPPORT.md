# Support

AgentOps is an early-stage open-source project. APIs may change before a stable 1.0 release.

## Where to ask

- Use GitHub Issues for reproducible bugs and feature proposals.
- Use GitHub Discussions when enabled for design questions and broader community discussion.
- Review the README and the security model in `docs/` before integrating AgentOps into a production system.

## Before opening an issue

Include the AgentOps version, SDK, runtime versions, a minimal reproduction, and sanitized logs. Never publish API keys, credentials, customer data, private prompts, or unredacted execution traces.

## Security reports

Do not report vulnerabilities in public issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Scope

The maintainers can review and discuss issues, but this project does not currently promise a commercial SLA, guaranteed response time, or production support contract.
